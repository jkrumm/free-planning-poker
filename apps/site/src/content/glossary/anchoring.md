Anchoring is the cognitive bias in which the first number a group hears sets a precedent for every estimate after it. Planning poker avoids it by having each person choose a card in private and reveal at the same time, so nobody has heard an answer before forming one.

The same goes for the discussion before the vote: nobody mentions a size. For remote teams, the tool has to keep estimates hidden until everyone has chosen.

## In the room

The server withholds every vote until the reveal, so no value reaches another browser early, not even in the network tab.
