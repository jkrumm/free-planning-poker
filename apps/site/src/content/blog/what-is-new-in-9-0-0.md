Version 9.0.0 changes the room for people who already use version 1. Rows that stay the same are left out.

**Decks.** Version 1 offered the Fibonacci cards from 1 to 21. Version 9.0.0 has the default deck, three more decks and a custom deck. A `?` card lets a player abstain from a vote.

**Final value.** A round no longer ends at the reveal. The team settles a final value, and the room keeps it for each topic.

**Locked rooms.** Anyone with the link can still get into a room by default. A room can be locked with a code, and the code travels in the link.

**Booked names.** A custom room name is now a booking. Numbers and names that nobody uses go back to the pool.

**Release times.** A room number is released three months after its last visit, and a booked name after six months. A released number or name still opens the room until it is handed to a new room.

**Reveal.** Votes can be revealed at any time after the first vote. If some seats are still thinking, the room asks for confirmation first.

**Auto flip.** Auto flip is a setting now, with a countdown that can be cancelled.

**Views.** The room shows a Table view or a Grid view. It picks one by the number of players, and you can switch between them.

**Timers.** The elapsed-time counter stays. An optional countdown joins it.

**Sounds.** The room has five sounds. They are off for new users.

**Celebration.** Confetti still plays on a unanimous vote. A streak counter joins it.

**Statistics.** The room statistics that sat in the sidebar are now in the Insights panel.

**Recent rooms.** The home page no longer jumps into the last room. Recent rooms are listed at `/room`, on the landing page and in a switcher inside the room.

**Settings.** The room reads your name and settings from local storage once and keeps them.
